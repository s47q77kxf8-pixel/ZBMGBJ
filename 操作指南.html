第一部分：简易上手

1. 打开应用

用浏览器打开项目里的 index.html，首次使用需联网。

2. 首次设置（建议先做）

  1. 点击导航 「我的」。
  2. 填 美工信息（ID、联系方式、默认工期）。
  3. 在 制品设置 添加常用制品（如吧唧、拍立得）并填价格。
  4. 在 系数设置 检查用途、加急、折扣等（有默认值）。
  5. 在 工艺设置 添加工艺（如烫色、白墨）及每层单价。
  6. 修改会自动保存到本机；可点底部 「立即保存」 再次写入。

3. 做一单报价

  1. 点击导航 「排单」 回到主页面。
  2. 点击 + 打开计算抽屉。
  3. 填 单主 ID、联系方式、开始时间、截稿时间（可选）。
  4. 选 用途、加急 等设置选项。
  5. 在 制品 区添加制品：选类型、数量、工艺等。
  6. 点击 「报价」，小票自动生成并加入排单。

4. 查看与保存小票

  • 小票抽屉会弹出：可点 「存图」 导出图片发给单主。
  • 已自动写入排单；在排单页月历和「当前批次」区可查看。
  • 点击排单卡片可 编辑、小票、备注、撤单、废稿、结单。

5. 常用入口

入口作用
排单主页面，月历与待办
+打开计算抽屉
我的美工信息、制品、系数、工艺
排单页右上 统计查看企划数、收入等
排单页右上 记录历史记录列表

第二部分：按页面详细描述

以下按页面、抽屉、弹窗逐一说明用法，方便按界面查找操作。

三、排单页（主页面）

3.1 如何进入

点击导航 「排单」；或从记录页/统计页点击「返回」。

3.2 区域与操作

工具栏（顶部）

  • ‹ / ›：月历上一月 / 下一月。
  • 日期按钮（显示年月）：点击打开日期选择器，选某日后月历跳到该月。
  • 昼夜模式：点击切换；长按（或右键）跟随系统。
  • 统计 / 记录：进入对应页。

月历区：按开始/截稿时间显示排单彩条；跨天显示跨日彩条。点击某条彩条：弹出该单的操作菜单。

当前批次（todo 区）

  • 筛选：当日（默认）/ 当月 / 待排 / 所有。Today 按钮：选中非今天时出现，点后回今日。
  • 排单列表：每项前有复选框，勾选表示制品已完成（进度跟进）。点击排单模块：弹出操作菜单。

四、计算抽屉

4.1 如何打开

点击导航 +：新建。排单卡片「编辑」：加载该单，改完可覆盖或另存。

4.2 如何关闭

左上 ×：不保存。报价：生成小票并加入排单，自动关闭并打开小票。另存为新单（仅编辑模式）：保存为新排单，关闭，不打开小票。

4.3 填写内容

区块内容
单主信息单主 ID、联系方式、下单/开始/截稿时间；「备注（智能提取）」打开备注弹窗，粘贴单主备注后点「智能提取」可自动识别制品与赠品；填开始时间+工期可自动算截稿
档期占位可设置预计制品数，方便预留时间
设置选项用途、加急、同模、折扣、平台费；右侧「模版填表」加载模板
每制品增加其他费用，可多选，为每个制品添加额外费用
平台费与定金选择平台后自动匹配手续费；可设置是否需要定金及定金比例
其他费用抠图费等，预设或自定义
制品/赠品类型、单双面、数量、同模、工艺；赠品在小票标为「赠品」可显示划线价

4.4 底部按钮

报价：生成并加入（编辑模式下覆盖原单）。另存为新单：仅编辑模式显示。保存为模板：输入名称保存当前组合。

编辑模式保存选择弹窗：在编辑模式下点击「报价」或从小票页点「排单」时，会弹出选择框：「覆盖原企划」 直接覆盖原单 / 「另存为新排单」 保留原单另存新单。该弹窗用于防止误覆盖，配合数据快照功能（见 二十六）双重保障数据安全。

五、小票抽屉

5.1 如何打开

计算抽屉点「报价」后自动打开；或排单卡片「小票」。

5.2 顶部操作

排单：保存到排单列表。主题：下拉选主题。小票设置：打开设置面板。复制：将小票复制为图片。存图：导出图片。返回计算页：关闭小票抽屉并打开计算抽屉，保留当前数据用于修改报价；编辑历史单时可用此按钮回到计算页调整后再保存。

5.3 报价金额 / 需付定金（顶部预览）

顶部展示 报价金额（不含平台费）。若在计算页选择「需要定金」，顶部会在报价金额下方展示 需付定金（按定金比例实时计算，样式与报价金额一致）。

5.4 约定实收

可填写与单主约定的金额；提供快速取整按钮：四舍五入 / 向上取整 / 向下取整 / 取整到十 / 取整到百。修改约定实收后，需付定金会同步更新。

5.5 已收定金

点击 「确认已收定金」 按钮后，可输入已收定金金额，支持快速取整操作。可点击「取消」按钮取消已收定金的确认。

六、小票设置面板（底部弹出）

小票抽屉内点「小票设置」打开。三个标签：设置（头图/尾图/标题等）、主题（边框/底纹）、字体。底部：清除设置、保存设置。

七、排单卡片操作弹窗

在月历上点击某条排单彩条，或在下方 todo 区点击某个排单模块，会弹出操作菜单，包含：

操作说明
编辑关闭菜单并打开计算抽屉，将该单数据加载到计算页。改完后可二选一：点击 「报价」 覆盖原记录；或点击 「另存为新单」 保存为一条新排单（原单不变）。
小票打开该单的小票视图，可查看报价明细；在此可保存图片或再点「排单」写回历史。
备注打开备注弹窗，可填写或查看该单的备注（仅本地保存，不会打在小票上）。
撤单打开结算弹窗，选择撤单（跑单），按设置页「跑单相关」规则填写跑单费金额等，确认后该单状态变为「已撤单」。
废稿打开结算弹窗，选择废稿，按设置页「废稿相关」规则填写废稿费金额等，确认后该单状态变为「有废稿」。
结单打开结算弹窗，选择正常结单，填写本次收款（默认本次应收）、优惠原因（每项单行：名称、减去/折扣、数值），会显示新平台费与实际单主支付，确认后该单状态变为「已结单」。

结算弹窗中的金额、备注会保存到该条记录，统计页会按结算结果统计收入/撤单/废稿金额。

八、结算弹窗

排单卡片选「撤单」「废稿」「结单」后打开。第一步选类型；第二步按类型填写（撤单：退全款或收跑单费；废稿：按设置页规则填；结单：填本次收款，默认本次应收，可勾选优惠原因、显示新平台费与实际单主支付）；第三步点「确定」保存。

九、记录页

排单页右上点「记录」进入；左上「返回」退出。

顶部：无导入/导出功能，相关功能已移至「我的页面」。

搜索/排序/筛选：搜索框、排序图标（弹层选时间/价格/单主）、筛选图标（打开筛选抽屉）。

筛选抽屉：显示方式（按月分组 / 全部排序）、时间范围、状态、价格范围；全选、批量删除。选「全部排序」时按当前排序规则整列表显示，不按月份分组。点「应用」关闭。

历史记录数量不限。数据在本地，换设备或清空会丢失，请及时导出备份。

十、统计页

排单页右上点「统计」进入；左上「返回」退出。

时间范围（在面板）：本月 / 本年 / 全部 / 自定义；选本月或本年时可切换月份或年份；选择本月/本年时显示环比上月/去年。

内容：KPI 卡片（无数据时显示「当前筛选条件下暂无企划数据」）、环比/同比、趋势图、数据分布、制品小类汇总、Top 单主（默认 10 条，点「更多」展开）、Top 制品榜。顶部：时光报告、筛选。

筛选抽屉：时间口径（按记录时间/按截稿日）、金额口径、赠品计入方式、企划状态；无时间范围（时间范围仅在面板）。点「应用」关闭。

十一、我的页面

导航「我的」进入。美工信息、制品设置、系数设置、结算配置（跑单、废稿、优惠原因）、工艺设置；导入 JSON（覆盖/合并）、导出 JSON/Excel。

添加制品弹窗：制品设置→「添加」。填分类、名称、计价方式及价格。恢复默认时制品为：固定价 50、单面 50 双面 80、基础 50 递增 30。

添加系数弹窗：系数设置→「添加」。填大类、小类、系数值。恢复默认时用途为 自用/无盈利、同人商用、买断、企业/书店；平台费 米画师/画加 5%。

添加工艺弹窗：工艺设置→「添加」。填名称、每层单价。

修改会自动保存到本机；底部 「立即保存」 可再次写入。「恢复默认设置」 还原为开放使用模板（用途/系数/制品如上），有二次确认。

十二、企划备注弹窗

计算页单主 「备注（智能提取）」 或排单卡片「备注」打开。查看模式只读；编辑模式可输入或粘贴单主发的备注，点击 「智能提取」 自动识别制品与赠品并填入报价表。支持多种写法（如「拍立得 单面 2个」「吧唧 10个」）；写简称（如「吧唧」）可匹配设置中的制品名（如「普通吧唧」）。赠品以「赠品：」开头后的行会识别为赠品。识别成功后有轻提示。点 × 或「确定」关闭。

十三、模板的保存与使用

保存：计算抽屉底部「保存为模板」，输入名称。加载：「设置选项」右侧「模版填表」→ 选模板 → 加载。模版填表内可删除模板。

十四、价格公式（供参考）

  • 单件制品价 = 基础价 × (1 + 同模系数×(柄图数−1)) + 工艺费用×工艺层数
  • 总价 = 各制品价相加 → 乘上加价类系数、折扣类系数 → 再加上其他费用合计与平台手续费

具体系数、工艺单价、其他费用以 设置页 当前配置为准。

十五、注意事项

  1. 数据在本地：设置与历史都存在本机浏览器，清空缓存或换设备会丢失，重要内容请保存图片或导出 JSON/Excel。
  2. 跨端同步：我的页面导入/导出 JSON，可选择覆盖或合并，用于不同设备间手动同步。
  3. 历史记录：数量不做限制，建议定期导出备份。
  4. 打印/导出：若小票被裁切，可调整打印边距或导出时缩放。
  5. 移动端：筛选采用抽屉式，点击「筛选」按钮打开。

十六、云端同步功能

登录与注册：打开 login.html 页面进行账户管理，支持新用户注册和现有用户登录，登录后可使用云端同步功能。

密码重置：打开 reset-password.html 页面，按照提示步骤重置密码。

数据同步：

  • 上传设置：将本地设置上传到云端，实现跨设备同步
  • 从云端恢复：将云端设置恢复到本地，覆盖本地数据
  • 企划同步：支持企划数据的云端存储与恢复
  • 批量删除同步：记录页批量删除时，云端数据也会同步删除

注意事项：云端同步需要联网，同步过程中请保持网络连接稳定，首次同步可能需要较长时间，取决于数据量大小。

十七、客户端页面

如何打开：直接打开 client.html 页面。

功能说明：提供给客户填写需求的表单页面，客户可直接填写详细需求，包括制品类型、数量、特殊要求等，简化沟通流程，减少信息传递误差。

使用方法：客户打开页面后按照表单提示填写需求信息，填写完成后可复制或截图发给美工，美工可根据客户填写的需求进行报价和排单。

十八、统计页隐私保护

功能说明：统计页提供隐私保护功能，可隐藏敏感信息，方便在公共场合展示数据。

隐私按钮：统计页顶部有两个按钮——隐藏金额（开启后所有金额显示为 ¥***）和 隐藏单主（开启后单主名保留第一个字）。

隐藏范围：开启「隐藏金额」后，核心指标、进度与结算、费用区域、趋势图、数据分布（所有 tab）、制品项汇总、Top 单主等所有区域的金额都会被隐藏。

IP名称归一化：自动提取 IP 的中文核心部分（如"变形金刚Transformers"→"变形金刚"），纯外文 IP 保留原样；悬停 IP 条目可查看所有原始写法。

数据分布排序：支持按名称、单数、金额排序，点击切换升序/降序。

接单平台统计：数据分布新增「接单平台」Tab，用于统计不同平台（QQ、微信、小红书等）的接单单数和金额，支持排序。

十九、智能提取功能增强

功能说明：企划备注弹窗的「智能提取」功能可自动识别单主备注中的信息，并填入计算页对应字段。

支持提取的字段：单主ID（主催、客户、甲方等）、联系方式（QQ、微信、电话等）、用途、原作、角色、生日、英文名、企划主题名、制品工艺及尺寸、是否需要抠图。

支持的输入格式：带符号写法（◆●•）、无符号写法（主催：张三）、无冒号写法（主催 张三）、制品编号写法（①②③、1. 2. 3.、- 等）。

智能匹配：自动匹配用途系数、从制品描述中识别工艺、检测「是否需要抠图：是」时自动添加抠图费用、无单位数字视为尺寸（数量默认1）。

使用方法：在计算页点击「备注（智能提取）」打开弹窗，粘贴单主备注后点击「智能提取」即可。

二十、系数计算模式

功能说明：系统支持加价类和折扣类系数分别选择计算模式（乘法模式或加法模式）。计算逻辑为先算加价类，再算折扣类。

配置位置：在 script.js 的 defaultSettings.pricingCalculationMode 中配置。

加价类系数：

  • 乘法模式：系数相乘（用途=2，加急=1.5 → 2×1.5=3 → 加价后价格=原价×3）
  • 加法模式：系数增量相加（用途=2，加急=1.5 → 1+(2-1)+(1.5-1)=2.5 → 加价后价格=原价×2.5）

折扣类系数：

  • 乘法模式：系数相乘（折扣=0.9，扩展折扣=0.95 → 0.9×0.95=0.855 → 折扣后价格=加价后价格×0.855）
  • 加法模式：系数增量相加（折扣=0.9，扩展折扣=0.95 → 1+(0.9-1)+(0.95-1)=0.85 → 折扣后价格=加价后价格×0.85）

小票显示：加价合计显示加价后的总价，折扣合计显示减少的金额；加法模式下系数明细显示增减金额，乘法模式只显示名称和系数值。

向后兼容：历史数据默认使用乘法模式，新数据保存计算模式和系数明细到 quoteData 中。

二十一、追加单关联功能

功能说明：支持原始订单与追加单的双向关联，方便管理同一客户的多笔订单。

创建追加单：在排单卡片操作弹窗中，点击「追加单」按钮，系统自动创建关联订单，计算页预填原单的单主信息，添加新制品和费用后点击「小票」生成追加单。

关联信息显示：追加单卡片显示「关联原单：XXX」，原单卡片显示「关联追加单：N个」，字体缩小至 0.65rem，左对齐。

关联跳转：点击追加单的「关联原单」跳转至原单；点击原单的「关联追加单」跳转至记录页，仅显示该原单的所有追加单。

取消关联：在追加单的排单卡片操作弹窗中，点击「取消关联」按钮，取消后追加单成为独立订单。

原单删除与恢复：原单删除后追加单显示「原单已删除」，原单恢复后追加单自动重新关联。

跨订单同模：创建追加单时，系统检测新添加的制品类型是否与原单相同，若相同会提示是否开启跨订单同模，默认关闭。

二十二、制品顺序调整

功能说明：计算页制品卡片支持置顶、上移/下移调整顺序，方便按客户需求或优先级排列制品。

调整方式：每个制品卡片右侧有 ⤒（置顶）、↑（上移）和 ↓（下移）按钮，点击即可调整顺序，移动后自动重新计算价格，不会跳转到小票页面。

注意事项：第一个制品无法置顶和上移，最后一个制品无法下移，调整顺序不影响价格计算结果。

二十三、回收站优化

三行显示格式：回收站条目采用三行显示格式，与记录页保持一致：

行数内容说明
第一行平台 + 单主ID如「QQ · 张三」
第二行企划名 · 原作 · 角色如「企划名称 · 作品名称 · 角色名」
第三行日期 | 状态 | ID | 删除时间如「2026-07-14 | 进行中 | ID:123456 · 2天前删除」

订单ID显示：每个回收站条目显示排单自动生成的ID，格式为「ID:XXX」。

恢复订单：点击回收站条目的「恢复」按钮，可将订单恢复到排单列表，关联关系自动恢复。

永久删除：点击回收站条目的「永久删除」按钮，订单将被彻底删除，无法恢复，请谨慎操作。

二十四、工艺费计费方式

功能说明：针对制品/赠品条目，可灵活选择工艺费的计费方式，解决「拍立得做2个但工艺层只做一次不应收2份工艺费」的实际场景。

计费方式：每个制品/赠品条目的「工艺类型」行右侧有计费方式下拉框，两个选项：

  • 按制品数（默认）：工艺费 = 工艺单价 × 制品/赠品数量
  • 只收一次：工艺费 = 工艺单价 × 1（不论数量多少，该条目下所有工艺费只计一次）

条目级独立：计费方式是条目级别的，制品和赠品各自独立配置互不影响；同一条目下所有工艺统一按同一种方式计费。

向后兼容：旧订单数据无该字段，默认为「按制品数」，行为完全不变。

小票展示：小票工艺行显示计费数量，「只收一次」时计费数量为1，自然体现一次性收费，不额外加文字标注。

二十五、多货币支持

功能说明：支持 26 种货币，所有金额展示（报价、手续费、定金、统计等）会根据所选货币显示对应符号，替代原本硬编码的「¥」。

入口：我的页面 → 基础设置 → 默认货币。

支持的货币：人民币(CNY ¥)、美元(USD $)、欧元(EUR €)、英镑(GBP £)、日元(JPY ¥)、韩元(KRW ₩)、港币(HKD $)、台币(TWD NT$)、澳元(AUD $)、加元(CAD $)、新加坡元(SGD $)、瑞士法郎(CHF Fr)、瑞典克朗(SEK kr)、挪威克朗(NOK kr)、丹麦克朗(DKK kr)、波兰兹罗提(PLN zł)、捷克克朗(CZK Kč)、匈牙利福林(HUF Ft)、泰铢(THB ฿)、印度卢比(INR ₹)、印尼卢比(IDR Rp)、马来西亚林吉特(MYR RM)、越南盾(VND ₫)、巴西雷亚尔(BRL R$)、墨西哥比索(MXN $)、南非兰特(ZAR R)。

搜索筛选：货币下拉框支持输入搜索，可通过 货币代码（如 USD）、货币名称（如 美元）、货币符号（如 $）快速筛选定位。

影响范围：小票所有金额显示、计算抽屉报价预览、记录页金额、统计页金额、设置页各项系数金额。

注：货币切换只影响显示符号，不进行汇率换算，金额数值不变。

二十六、数据快照与恢复

功能说明：为防止误操作导致数据丢失，系统在关键操作前自动创建数据快照，可随时从快照恢复。

自动快照触发时机：

  • 保存到历史记录前：每次点击「保存」「排单」「覆盖」「新单」时，先创建当前数据快照
  • 编辑模式覆盖原企划前同样会创建快照

恢复入口：我的页面 → 恢复数据（黄色按钮）→ 弹出快照列表对话框。

恢复操作：

  1. 对话框展示所有可用快照（按时间倒序）
  2. 点击某条快照的「恢复」按钮
  3. 系统会先将当前数据保存为新快照（防止恢复后反悔）
  4. 再将选中快照的数据覆盖到当前

配合编辑模式保存选择弹窗：编辑模式下点「报价」或小票页点「排单」时，会弹出选择框：覆盖原企划 直接覆盖原单 / 另存为新排单 保留原单另存新单。该弹窗 + 数据快照双重保障，避免误覆盖丢失数据。

注：快照存储在浏览器本地 localStorage，不会上传云端，清理浏览器数据会丢失快照。

二十七、文件夹名生成规则

功能说明：排单卡片操作弹窗中点击「复制文件夹名」会按统一规则生成文件夹名，方便归档整理。

命名格式：

时间【平台 单主ID】[加急-]企划名-原作-制品数（制品详情）
字段说明示例
时间根据所选时间类型（下单/开始/截稿）20260805
平台 + 单主ID方括号包裹【米画师 ABC123】
加急前缀加急订单在企划名前加 加急-加急-
企划名企划信息中的企划名夏日企划
原作企划信息中的原作（IP）原神
制品数所有制品总数制品3
制品详情各制品类型+数量，+ 连接（拍立得2+亚克力1）

追加单合并：生成原单文件夹名时，会 合并原单和所有追加单的制品信息。制品数 = 原单制品数 + 所有追加单制品数；制品详情按顺序拼接所有制品。

二十八、平台手续费取整开关

功能说明：每个平台手续费可独立配置「是否四舍五入取整」，解决不同平台手续费精度需求不同的场景。

入口：我的页面 → 系数设置 → 其他类 → 平台手续费 → 每行右侧「取整」复选框。

平台默认取整
无否
米画师是
画加否
新增平台否

取整规则：

  • 取整（开）：Math.round(基数 × 费率) 取整到元。例：9.444 → 9
  • 不取整（关）：保留两位小数。例：9.444 → 9.44

历史数据兼容：旧数据无 round 字段时，米画师默认取整、其他默认不取整，与上述默认值一致，无需迁移。

与约定实收的联动：修改「约定实收」会重算平台手续费，重算时同样遵循该平台的取整开关设置。

二十九、按字数收费

功能说明：为文字类制品（如文章、小说、文案等）新增第 5 种计价方式 「按字数收费」，支持自定义「每 X 字 Y 元」的灵活单位配置。计算页填写字数后，系统按 单价 × 字数 ÷ 单位 自动计算基础价，并参与同模系数和工艺费计算，与固定价/单双面价/基础+递增价等计价方式行为一致。

计价方式对比：

priceType说明basePrice 计算同模/工艺费
fixed 固定价按固定单价price参与
double 单双面价按单/双面priceSingle 或 priceDouble参与
config 基础+递增价按配置项basePrice × baseConfigCount + 额外配置参与
nodes 按节点收费用户填总价nodeTotalPrice不参与
byChar 按字数收费按字数charPrice × charCount ÷ charUnit参与

制品类型配置：我的页面 → 制品设置 → 新增/编辑制品类型时，「计价方式」下拉框选择 「按字数收费」，配置以下两项：

配置项说明示例
每单位价格（元）每个「字数单位」对应的单价5（即 5 元/千字）
字数单位计费字数单位每字 / 每百字 / 每500字 / 每千字（默认）/ 每万字

字数单位提供 5 个预设选项，覆盖从短文到长篇小说的常见计费场景。字数本身是每次订单不同的值，由用户在计算页填写，不是制品类型的固定属性。

计算页使用：

  1. 选择「按字数收费」类型的制品，卡片显示「单价：¥X/单位」和「字数」输入框
  2. 在字数输入框填入本次订单的字数（如 3000）
  3. 基础价实时计算：5 × 3000 ÷ 1000 = ¥15.00
  4. 同模、工艺费、系数等照常参与计算

小票展示：小票按「名称 | 单价 | 数量 | 小计」4 列布局展示，字数智能格式化，避免几十万字撑爆列宽：

字数单价单价列数量列小计列
30005元/千字¥5/千字3000字¥15.00
350005元/千字¥5/千字3.5万字¥175.00
3500005元/千字¥5/千字35万字¥1750.00
50000050元/万字¥50/万字50万字¥2500.00

显示规则：

  • 字数 < 1万：显示原值（如 3500字）
  • 字数 ≥ 1万：显示「X万字」，整数不显示小数，非整数保留 1 位（如 1万字、3.5万字、35万字）
  • 鼠标悬停数量列，title 属性显示完整字数（如 字数：350000字 × 1件），保证精度可查
  • 单价列含货币符号（如 ¥5/千字），与其他类型单价显示一致
  • 同模时追加子行，分别展示首件价与同模价

智能提取：备注智能提取支持识别字数信息，仅对「按字数收费」类型的制品生效。识别模式为 数字 + 字/千字/百字/万字。例：「文章3000字」→ 自动填充 charCount = 3000；「3万字」→ charCount = 30000。

赠品支持：赠品与制品对称实现「按字数收费」，配置方式、计算逻辑、小票展示均一致。赠品行以 [赠品] 前缀标识，划线价显示原价，实付显示 ¥0.00。

互转与历史恢复：

  • 制品 ↔ 赠品互转：charCount 字段保留，转换后无需重新填写字数
  • 历史恢复：保存含按字数收费制品的订单到历史记录，重新编辑时字数正确恢复

向后兼容：旧订单数据无 charCount、charPrice、charUnit 字段，默认按 charCount = 0、charUnit = 1000、charPrice = 0 处理，不影响现有功能。
